# Proguiz

Proguiz is a full-stack, browser-based web application designed to test and reinforce programming language concepts through interactive quizzes.

## Features
- **User Authentication:** Secure registration, login, and session management.
- **Interactive Quizzes:** Dynamic quiz modules and flashcards for learning core coding concepts.
- **Score Tracking:** Automated backend processing to record and display user performance results.

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP, Apache
- **Database:** MySQL

## Getting Started
1. Clone the repository into your local server environment (e.g., XAMPP `htdocs`).
2. Configure your database connection in `db_connect.php`.
3. Run Apache and MySQL, then open `index.php` in your browser.
