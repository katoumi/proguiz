# Proguiz

Proguiz is a full-stack, browser-based web application designed to test and reinforce programming language concepts through interactive quizzes[cite: 1, 7].

## Features
- **User Authentication:** Secure registration, login, and session management.
- **Interactive Quizzes:** Dynamic quiz modules and flashcards for learning core coding concepts[cite: 7].
- **Score Tracking:** Automated backend processing to record and display user performance results[cite: 7].

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript[cite: 7]
- **Backend:** PHP, Apache[cite: 7]
- **Database:** MySQL[cite: 7]

## Getting Started
1. Clone the repository into your local server environment (e.g., XAMPP `htdocs`).
2. Configure your database connection in `db_connect.php`[cite: 7].
3. Run Apache and MySQL, then open `index.php` in your browser.
